📋 Automate the follow-up

  • Set a keyword auto reply for frequent questions about prices, stock or delivery.
  • Build a separate chat flow for each message so a support request reaches a different reply from a sales enquiry.
  • Organize contacts and groups, then schedule personalized messages for the audience that opted in.
  • Track leads and conversation history across your connected accounts.

📘 Try your first button message

  1. Install LeadWave and open it to find your device code.
  2. Send the code to support and enter the trial key you receive.
  3. Connect your WhatsApp number, create a button template and send it to a test contact.
